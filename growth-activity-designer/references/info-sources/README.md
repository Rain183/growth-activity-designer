# 信息量地图（S2 信息装载的唯一索引）

按方法论模块组织，每模块一个 md（预算管理归业务方，不设模块）。**动静分层是本库的核心设计**：

- **静态规则层**（低频变化）：权益规则、触点规则、逆向处理先例、系统机制——**内容直接固化在本库**（见 assets-toolbox / reverse-checklist / exposure-touchpoints 及各模块文件）；
- **动态数据层**（周/月更）：指标基线、客群分布、在投活动清单、流量水位——**本库只存取数口径与获取路径，不存数值**。S2 运行时按口径向使用者索要当期数值，索取清单按获取方式四类给路径：系统直查（BI 取数口径）/ 文档索要 / 线上实测 / 人工请示。

> 为什么不存数值：数值会过时，skill 里放会腐化的数，第二次运行就是错的。信息件骨架域无关——换业务域只换本目录的实例（来源系统与字段），S 流程与方法论不动。
