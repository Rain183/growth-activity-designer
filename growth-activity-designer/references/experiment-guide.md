# S6 实验设计指引

## 先答两问

1. **能不能 AB？**（战略口径是否要求统一面客/是否需要双份实现成本/流量是否远大于名额）——不能 AB 就设计分段漏斗观测或绝对收益评估，写明理由；
2. **要不要 AB？**——杠杆参数无先验最优值的必须实验（实验是必要过程非可选）；已被同类活动验证过的惯例交互不实验。

## 实验点盘点法

把 S3-S5 的全部可变项列成盘点表：实验点 × 类型（功能型=定参数验机制 / 效果型=触点放大）× 是否实验（必须/可/无法-基石能力/无需-惯例）。**功能型先行，效果型在后**；效果型各触点独立分层验证，不做两两叉乘（除非极大流量改版）。

## 分流与对照设计

- 用户级分流；**周期累计型活动全周期锁组**（会话级分流无法归因进度与奖励）；
- **首行放分流公平性检查**：分组前行为指标（如频道访问率/资产结构）组间 p>0.05 才继续判读；
- **对照组同口径统计**（周期达标型专用）：对照组按与实验组完全相同口径统计"若有活动会达标"的人数但不发奖——实验组达标率−自然达标率=真实激励出的增量人群，这是档位/门槛的判读标准（差值小=白送，参与率低=够不着）；
- 触达/组合型改动：设"单点组×N + 组合组 + 对照组"——单点可能不显著而组合显著（体系化复合效应），实验设计要能把这件事测出来。

## 指标三层

| 层 | 要求 |
|----|------|
| 北极星 | 与 S1 画像一致，增量口径（实验组−对照组），不是总量口径 |
| 替代指标 | 核心指标观测窗口＞实验周期时，选短窗口高相关替代指标并给出历史折算系数（如 7日口径≈30日口径×60%），实验全程用替代指标 |
| 护栏指标 | 不能变差的指标（典型：结算转化率、整体购频、退款率）；周期型玩法加**防透支护栏**（达标者下期行为回落幅度） |

## 成本判读

- 增量成本率 = 奖励总成本 ÷ 增量（实验组−对照组的目标行为金额），**不许除以总量**（奖励发给含自然达标者的全部达标者，除总量虚报效率）；
- 全量判读走绝对价值：增量收益（按含权益成本的净利口径核算）− 奖励成本 ≥ 0。

## 判读纪律

跑满完整活动周期才判读；判读期取常态运营期；样本量先算后开组（按入口量级与最小可检测差异反推每组流量与周期，算不出显著性就不开组）；p<0.05 显著、0.05-0.2 近显著值得关注。
