# 玩法库（S3 第一步"指标倒查"的检索对象）

每玩法一个 md：结构（动作+条件+奖励骨架）/ 适用指标 / 成本结构 / 已验证案例 / 参数经验区间 / 已知风险。

| 条目 | 适用北极星 |
|------|-----------|
| `p1-比例返卡型.md` | 客单价、复购 |
| `p2-单品购返型.md` | 权益渗透、复购（登门槛） |
| `p3-充值加赠型.md` | 首充/开卡 |
| `p4-周期累计达标型.md` | 周期行为聚合（购频/复充） |
| `p5-全链路触达强化型.md` | 渗透率、权益使用率（不新增权益成本） |
| `p6-每日概率抽奖型.md` | 访频、日活 |
| `p7-门槛券包型.md` | 新增用户、首购转化、召回 |

**奖励是插槽，玩法骨架与具体权益解耦**：每个条目的"结构"里，奖励段可按 `../assets-toolbox.md` 的选奖励两判据替换（比例返可返券、周期达标可兑实物、日频抽奖可出京豆）——倒查玩法库匹配的是"动作+条件"骨架与适用指标，不是奖励类型。案例里的权益选择只是该次活动的判断结果，不是骨架的一部分。

> 维护规则：新活动方案定稿后回流登记为新条目或更新参数区间（产出回流机制）。概率抽奖型条目（p6）为盲测判分后回流入库。
