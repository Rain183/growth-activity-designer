# 03 活动规则（S3）· 盲测方案

## 候选玩法对比与选型

| 候选 | 判定 | 排除/选定理由 |
|------|------|--------------|
| 比例返卡型（p1） | 排除 | 依赖下单动作，拉不动"日访问"这个高频轻行为 |
| 单品购返型（p2） | 排除 | 同上，且成本挂商品毛利与访频目标错位 |
| 充值加赠型（p3） | 排除 | 拉充值不拉访频 |
| 全链路触达强化（p5） | 排除 | 无"每日回访"的行为钩子 |
| **每日概率抽奖型（新结构，由缺口反推）** | **选定** | 日频轻动作+即时随机反馈是拉访频的经典结构；小额权益成本可日度控盘 |

## 触发规则

| 字段 | 内容 |
|------|------|
| 动作 | 每日进入频道点击抽奖 |
| 命中条件 | 每用户每日 1 次基础机会（零下单要求）；完成指定浏览/下单任务可加抽（任务型加成，实验位）。金额口径不适用：动作为访问非消费；商品池不适用：不挂商品（加抽任务若含下单，沿用任务所属活动的商品口径） |
| 发奖条件 | 抽即开奖、实时到账 |
| 奖励 | 概率型组合：小额超市卡赠金（30天有效）为主 + 品类券兜底 + 稀有大额卡作头部氛围奖 |

## 杠杆参数（全部实验位）

- 中奖率结构：赠金/券/大奖/未中四档概率分布（实验位：以期望成本≤日常池口径反推区间）；
- 赠金面额区间与大奖面额（实验位）；
- 加抽任务次数上限（实验位）。

## 基本规则

时间：常驻日频；区域：全国；人群：全量登录用户；单用户每日机会数封顶；活动总发奖=按日成本上限与库存管理。逐项理由见决策点汇报表。

## 互斥扫描（覆盖在投清单 100%，逐条判定）

| 在投活动 | 权益冲突 | 场景冲突 | 判定 |
|---------|---------|---------|------|
| 消费挑战（周期达标） | 实物达标奖 vs 日频小额随机奖，层级不同 | 频道楼层排序协调 | 不互斥 |
| 满额返/单品购返 | 返卡挂下单动作，本活动挂访问动作 | 无同位竞争 | 不互斥 |
| 刮卡类日频（如在投） | **同为日频概率型，权益与场景双重叠** | 同楼层竞争 | 互斥——需二选一或错档运营，列入请示项 |
| 新人类活动 | 面向新客 | 楼层错位 | 不互斥 |
