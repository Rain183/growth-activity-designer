# 05 曝光动线（S5）

## 用户状态枚举

| 状态 | 定义 |
|------|------|
| A | 沉默未触达 |
| B | 已触达（短信/PUSH 发出）未进频道 |
| C | 已进频道未领券 |
| D | 已领券未下单 |
| E | 已下单未核销 |
| F | 已核销（首单完成） |
| G | 已退款 |

## 触点矩阵（触点×用户状态，按状态分内容）

| 触点 | 域 | 呈现内容 | 展示状态 | 前置条件/红线 |
|------|----|---------|---------|--------------|
| 定向触达（短信/PUSH） | 公域 | 召回钩子文案+券包直达链接 | A（仅沉默人群包） | 触达名单=沉默人群包；频率上限防打扰；触达覆盖率先例 1.8%→27.2%（效果型实验轮验证） |
| 频道首页召回楼层 | 私域 | 召回券包入口（利益点=3 张阶梯券） | B、C | 仅对沉默用户呈现；与在投楼层（每天来抽卡等）排序协商；不满足人群包**不呈现** |
| 活动落地页 | 私域 | 领取按钮+券包明细+用券指引+凑单组件 | C | 清晰利益点与可得上限明示；领取即发 |
| 券资产位/资产页 | 私域 | 已领券展示+临过期提示（7 日内） | D | 新券包类型接入；临近过期叠加紧迫性文案 |
| 我的页资产区 | 私域 | 券提醒 | D | **仅对已领券状态用户展示**（无券用户展示无意义） |
| 搜索结果页标签 | 公域 | 召回活动标签 | C、D | 标签次序遵守既定规则（一级/品类/二级），跨团队协商项 |
| 商详页价格区 | 公域 | 券利益点紧邻价格（接近原则） | D | 不满足券门槛的订单**不呈现**；商品主图角标可同步 |
| 购物车 | 公域 | 凑单提示+券可用明细 | D | 夹层形式，不打断流程 |
| 结算页 | 公域 | 用券终值强化 | D、E | **红线一：不满足门槛不呈现**；**红线二：不新增打断结算流程的促销内容**（峰终定律，终值强化用品牌 ICON+顺序优化类潜意识感知，不加交互打断） |
| 订单确认页 | 公域 | — | E | **红线三：不导流**（既定规则） |
| 逆向流程提示 | 公域 | 退款时告知已获权益将被回收 | G | 挽留与告知；72 小时内集中回收窗口 |

## 体系化规律与协商方

- 触达类单点效果微弱（实测多次单点不显著），**只有全链路体系化覆盖才产生可度量复合效应**：本方案按"触达→进频道→领券→凑单→结算"成组设计，实验按"单点组+组合组"验证（见 S6 轮二）；
- 跨页面判断逻辑走统一查询服务（用户 ID+场景枚举→展示逻辑），避免各页面口径不一致；
- 需协商方：频道运营（楼层排序）、搜索团队（标签次序）、客服侧（退款文案会签）、市场部（触达通道成本承担）。
