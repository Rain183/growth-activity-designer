# 03 活动规则（S3）

## 候选玩法对比与选型

| 候选 | 判定 | 排除/选定理由 |
|------|------|--------------|
| 比例返卡型（p1） | 排除 | 拉单笔不拉周期；返卡奖励与"拉充值"目标反向（系统再送余额，降低充值必要性） |
| 单品购返型（p2） | 排除 | 目标是权益渗透，与复充北极星错位 |
| 充值加赠加码（p3） | 排除 | 无行为绑定（充完可能不花）；加赠比例是既定经营决策，回调即历史倒车 |
| 全链路触达强化（p5） | 排除 | 无权益杠杆，复充缺的是"理由"不是"看见" |
| **周期累计达标型（新结构，由缺口反推）** | **选定** | 档位倒逼充值+周期消费保证去化，一个机制串起"充值→消费→清零→再充"循环 |

## 触发规则

| 字段 | 内容 |
|------|------|
| 动作 | 周期内使用超市卡支付下单 |
| 命中条件 | 卡支付金额计入进度（**含本金+赠金**）；商品限京东超市自营，特殊商品排除清单（虚拟/预售/套装/定期购/秒送类）不计入；开启挑战前的周期内订单也计入 |
| 发奖条件 | 主动选奖品开启挑战 + 周期（月）内累计达标；每期一次，达标领奖即止 |
| 奖励 | 选定的实物奖品以 0.1 元兑换（奖品池 5 个 SKU 按档分组，价值≈档位的 3% 量级，实验位）；不用返卡类奖励（与北极星反向） |

## 杠杆参数（全部实验位）

- 挑战档位：双档制（低档+高档，奖品池 5 个 SKU 按档分组；实验位：低/标准/高三种双档组合对照，档位设计逻辑=常规充值档与余额的组合缺口，"光靠余额够不着、充值组合正好够"）；
- 奖品价值：各档位的 3% 量级（实验位）；
- 周期长度：月（与月购频指标对齐，首期不实验）。

## 基本规则

时间：月度滚动常驻（视判读续期）；区域：全国；人群：全量登录用户可见、实际参与集中于有余额/开卡用户（门槛天然筛选，无需硬性圈人）；单用户每期一次；总发奖上限=奖池库存管理（先到先得）。逐项理由见决策点汇报表。

## 互斥扫描（覆盖在投清单 100%，逐条判定）

| 在投活动 | 权益冲突 | 场景冲突 | 判定 |
|---------|---------|---------|------|
| 满额返（比例返卡） | 返卡 vs 实物奖，目标不同（单笔客单 vs 周期复充），卡消费互相成就 | 楼层错位 | 不互斥 |
| 单品购返 | 返卡面额小、目标为渗透 | 无同位竞争 | 不互斥 |
| 充值赠金（常驻） | 挑战放大充值动机，赠金是其既有组成 | 充值页同链路、互相成就 | 不互斥 |
| 每天来抽卡/刮卡类日频 | 小额赠金激励，与实物达标奖不同层 | 频道页楼层排序需协调 | 场景侧协调后不互斥 |
| 新人类活动（一元包邮/三单礼） | 面向新客，本活动实际面向有余额存量 | 新人楼层更前，利益点差异显著 | 不互斥 |
